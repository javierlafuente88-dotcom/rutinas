¿Cómo cargo un GIF nuevo?
  1. Entrá a GitHub → repositorio rutinas → carpeta gifs.
  2. Add file → Upload files, arrastrá el GIF o el video y tocá Commit changes.
  3. Esperá 1 o 2 minutos y recargá esta página: el ejercicio aparece solo en la lista.

El nombre del archivo es el nombre del ejercicio: press-banca.gif o press-banca.mp4 aparece como "Press banca". Usá minúsculas y guiones, sin tildes.
